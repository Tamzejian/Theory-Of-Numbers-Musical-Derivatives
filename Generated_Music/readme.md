# Algorithmic experimental

This is an essay to create and to treat the music generated by an algorithm based on prime numbers.
The rhythmic outcome is irregular and interesting from a music point of view.
However, this is a musical experimentation and no intention of "grand art."

Description of generated score:
IA helps solve many technical issues (and for the lack of a formal computer science/programming knowledge).

## I - Python

### First step: 
By using the Sieve of Eratosthenes, an algorithm generates a list of prime numbers up to a given limit corresponding to a multiple of 4 (Carrure).
We start by 5 since 3 = 0 (mod 3) and 2 = -1 (mod 3).
The primes are coded in (modulo 3) and then 1 is subtracted; this gives a binary sequence (0 and 1).
- 0 : is silence (in eigthts)
- 1 : is a sound (also in eigthts)

### Second step: 
The program counts the numbers of 1 (notes) and generates again a list of primes, of this number of 1s, and codes them in modulo 12 (chromatic scale). For the same reasons as for rhythm, we omit 2 and 3. We observe an interesting 'dance' of an arpeggio of the G7^-5 chord.

###  Third step: 
The program 'injects' notes over the rhythms.

### Fourth step:
Generating a musical code for LilyPond. The resulting file is a "rough score" (prime_music.ly).

## II - LilyPond & MuseScore:
A score is made from the generated file and then exported as MusicXML to be opened and treated in MuseScore.
At this level, the considerations are purely musical, exploiting the rhythmic characteristics of the generated material.

Lilypond has superior engraving qualities, but Musescore is preferred for the quality of sound.
